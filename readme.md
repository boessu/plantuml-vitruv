# PlantUML Archimate render pipeline
A small library which generates PlantUML source. Can be used e.g. for reports.

## Features
Beside of generating proper PlantUML source, the library can generate consolidated views.

## Documentation

### Building the docs

The documentation site is actually a Maven site, and its sources are included in the project. If required it can be generated by using the following Maven command:

```
mvn verify site
```

The verify phase is required, otherwise some of the reports won't be generated.

## Usage

The application is coded in Java, using Maven to manage the project.

It is a Java library, meant to be included as a dependency on any project which may want to make use of it.

### Installing

It is always possible installing it by using the usual Maven command:

```
mvn install
```
